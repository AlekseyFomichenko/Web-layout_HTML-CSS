# Интернет-магазин (учебный проект) | HTML/CSS

[![GitHub last commit](https://img.shields.io/github/last-commit/AlekseyFomichenko/Web-layout_HTML-CSS)](https://github.com/AlekseyFomichenko/Web-layout_HTML-CSS)
[![GitHub code size](https://img.shields.io/github/languages/code-size/AlekseyFomichenko/Web-layout_HTML-CSS)](https://github.com/AlekseyFomichenko/Web-layout_HTML-CSS)

Учебный проект интернет-магазина с адаптивным дизайном. Реализован на чистом HTML и CSS с акцентом на **семантическую вёрстку**, **BEM-методологию** и **кроссбраузерность**.

## 📌 Особенности
- **Адаптивный дизайн** (Mobile First + Desktop)
- **Семантическая разметка** (header, section, footer)
- **БЭМ-именование классов** (блоки, элементы, модификаторы)
- **CSS-переменные** для цветов и шрифтов
- **Оптимизированная загрузка** (сжатые изображения, lazy load)
- Форма обратной связи с валидацией (если есть JS)

## 🛠 Технологии
- HTML5 (Canvas, SVG — если использовались)
- CSS3 (Flexbox, Grid, анимации)
- Методология BEM
- Figma (если вёрстка по макету)
